⚡ Quick Start
1
ติดตั้ง dependencies: pip install flask flask-cors flask-socketio psutil requests cryptography
2
รัน server: python3 server.py
3
เปิดเบราว์เซอร์: http://localhost:5000 หรือ http://<IP ของเครื่อง>:5000 จากมือถือ
4
พิมพ์ /help ใน Terminal เพื่อดูคำสั่งทั้งหมด หรือแค่พิมพ์ประโยคภาษาไทยคุยกับ AI ได้เลย
💡 ARIA ใช้ Ollama ในเครื่องตัวเอง — install ได้ที่ ollama.ai แล้ว run: ollama pull qwen2.5:7b
📲 Install on Phone / Desktop
⚠ ต้องเปิด ARIA จาก IP จริงของเครื่อง (ไม่ใช่ localhost) เช่น http://192.168.1.100:5000 ถึงจะเชื่อมจากมือถือได้
🤖
Android (Chrome)
เปิด ARIA ใน Chrome → แตะเมนู ⋮ → "Install app" หรือรอ popup ปรากฏ
🍎
iOS (Safari)
เปิดใน Safari → กด Share ☐↑ → เลือก "Add to Home Screen" → Add
💻
Desktop (Chrome/Edge)
เปิด ARIA → แถบ URL มีไอคอน 📲 → คลิก Install → Open
🌐
Offline Mode
หลัง install แล้ว ARIA ทำงาน offline ได้สำหรับหน้าที่ cached ไว้
✓ หลัง install แล้วจะเหมือน native app — มี icon บน home screen, fullscreen ไม่มี browser bar
⌨ Terminal Commands
💡 ไม่มี / นำหน้า = คุยกับ AI โดยตรง  |  มี / = คำสั่งระบบ  |  Tab = autocomplete

🧠 AI Memory

ทุก chat ถูก save ใน SQLite อัตโนมัติ AI จำบทสนทนาข้ามเซสชั่นได้

Commandหน้าที่
/memory statsจำนวน messages, sessions, facts, ขนาด DB
/memory search <query>ค้นหาใน memory ทั้งหมด
/memory fact ชื่อ: Jaochaiบันทึก fact สำคัญ (AI จะจำตลอดไป)
/memory clearลบ memory ทั้งหมด
⏰ Task Scheduler

Task รัน background อัตโนมัติทุก 10 วินาที check — รองรับ 3 ประเภท

Command Typeตัวอย่าง
shell: .../tasks add Backup|shell:cp db.sqlite backup/|86400
รัน shell command ทุก 24 ชั่วโมง
alert: .../tasks add Morning|alert:Good Morning|สวัสดีตอนเช้า|28800
ส่ง ntfy notification ทุก 8 ชั่วโมง
http: .../tasks add Ping|http://example.com/health|300
Ping URL ทุก 5 นาที
/tasks listดู jobs ทั้งหมด พร้อมสถานะ + runs
/tasks run <id>รัน task ทันที (ไม่รอ interval)
/tasks logs <id>ดู log ย้อนหลัง 5 ครั้งล่าสุด
/tasks remove <id>ลบ task
🤖 AI Agent / Auto-pilot

Available Toolsทำอะไรได้

read_file / write_fileอ่าน/เขียนไฟล์

1

🔐 E2E Encrypted Chat
1
Node A: /echat setup mypassphrase → ได้ key + fingerprint
2
แชร์ key ให้ Node B (ผ่าน QR หรือข้อความ)
3
Node B: /echat join <key>
4
ทั้งสอง verify fingerprint ตรงกัน → chat ได้: /echat send <message>
✓ Fernet AES-128-CBC + HMAC-SHA256 | ต้องติดตั้ง: pip install cryptography
🤖 Bot Bridges (Discord + LINE)
BotSetup
Discord 1. discord.com/developers → New App → Bot → Copy token
2. ตั้ง DISCORD_TOKEN + DISCORD_CHANNEL ใน Settings
3. Webhook URL: /api/bot/discord/webhook
LINE 1. developers.line.biz → Create channel → Messaging API
2. ตั้ง LINE_CHANNEL_SECRET + LINE_ACCESS_TOKEN
3. Webhook URL: http://<IP>:5000/api/bot/line/webhook
4. ใช้ ngrok ถ้า IP ไม่ public: ngrok http 5000
💡 ส่งคำสั่งผ่าน LINE ได้เลย เช่น พิมพ์ "/weather Bangkok" ใน LINE แล้ว ARIA ตอบกลับ
